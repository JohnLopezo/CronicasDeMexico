# Crónicas de México

**Crónicas de México** es un videojuego RPG de acción y aventura en desarrollo, creado con Unity 6 y C#, que combina gráficos 2D con escenarios tridimensionales mediante una estética HD-2D.

El proyecto busca ofrecer una experiencia de exploración y fantasía inspirada en la historia, las culturas y la mitología de México.

## Características previstas

- **Exploración:** escenarios inspirados en antiguas civilizaciones mexicanas.
- **Combate:** enfrentamientos contra criaturas, enemigos y guardianes.
- **Mazmorras:** templos y desafíos con distintos niveles de dificultad.
- **Personajes:** protagonistas inspirados en animales representativos de México.
- **Habilidades elementales:** poderes de agua, fuego, tierra, viento, luz y oscuridad.
- **Progresión:** desbloqueo de habilidades, mejoras y nuevas regiones.
- **Estilo HD-2D:** personajes pixel art integrados en escenarios 3D con iluminación y efectos visuales modernos.

## Tecnologías

- Unity 6
- C#
- Universal Render Pipeline (URP)
- Claude Code como herramienta de asistencia al desarrollo
- Git y GitHub para control de versiones

## Estado del proyecto

**En preproducción y desarrollo inicial.**

El proyecto comenzará con un prototipo jugable inspirado en la cultura olmeca, que servirá como base para implementar las mecánicas principales y ampliar progresivamente el mundo del videojuego.

## Objetivo

Crear un videojuego con identidad visual propia que combine entretenimiento, exploración y elementos culturales de México, mediante una arquitectura escalable y preparada para futuras plataformas.
